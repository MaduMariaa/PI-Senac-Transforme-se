# PI---Senac-Transforme-se
Projeto Integrador do curso de Desenvolvimento Front-End "Transforme-se", promovido pela Serasa Experience com o Senac Largo Treze e a Gerando Falcões. Consiste na criação do 1° site da nossa cliente, dona de um pet shop, com vitrine para apresentar o estabelecimento e produtos, assim como um formulário para confirmação de agendamento: banho/tosa.
